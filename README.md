# Data Cleaning Utility  
**SYNTEXHUB – Data Science Internship Project**

## 📌 Project Overview
This project focuses on cleaning and preprocessing raw customer data to make it suitable for analysis.  
The dataset contains common real-world issues such as missing values, duplicate records, inconsistent formatting, and incorrect data types.

The objective is to build a simple and effective **Data Cleaning Utility** using Python.

---

## 🎯 Objectives
- Identify and handle missing values
- Remove duplicate records
- Standardize column names and formats
- Correct data types
- Generate a clean, analysis-ready dataset

---

## 🛠 Tools & Technologies Used
- Python  
- Pandas  
- NumPy  
- Google Colab  

---

## 📂 Dataset Information
### Raw Dataset:
- **File:** `raw_data.csv`

### Cleaned Dataset:
- **File:** `cleaned_customer_data.csv`

The dataset represents **customer-related data** containing inconsistencies that commonly appear in real-world datasets.

### Issues Identified in Raw Data:
- Missing values
- Duplicate entries
- Inconsistent text formats
- Incorrect or mixed data types

---

## 🔄 Data Cleaning Steps Performed
1. Loaded the raw dataset using Pandas
2. Inspected data structure and missing values
3. Handled missing values using appropriate techniques
4. Removed duplicate records
5. Standardized column names
6. Corrected data types where required
7. Saved the cleaned dataset to a new CSV file

---

## 📊 Output
- `raw_data.csv` → Original dataset  
- `cleaned_customer_data.csv` → Cleaned and processed dataset  

The cleaned dataset is ready for further analysis or machine learning tasks.
